# Portfolio fonts

Locally hosted Latin variable fonts from Google Fonts:

- **Newsreader**, regular and italic, weights 400–600, for editorial headings.
- **Source Sans 3**, weights 400–700, for body text and numeric metadata.

Both are distributed under the SIL Open Font License; the licenses are included
in this directory. System fonts provide Chinese and other fallback glyphs.
Serving these assets locally avoids an external font request on each visit.
